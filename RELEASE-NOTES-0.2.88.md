# Studio 0.2.88 — Creator memory and master clothing kit

This beta update combines the master clothing kit with lighter Creator startup
and more complete error reports. Update through Settings, then close Studio,
Unreal and the game so the update can apply. Reopen Studio before testing.

**Create → Make clothes** now has two clear actions: choose a character for a
clothing project, or open the master references in Blender. The master includes
the three classic bodies, clothes and accessories, grouped by character. Green
Body/Face references make clipping visible without changing native geometry,
UVs, weights, bone contracts or material data. Studio opens a separate working
copy and retains the verified master. Reference objects stay out of clothing
imports. Body-specific fitting and game checks remain necessary.
Studio unlocks the isolated garment's rig for FBX export, so reference viewing
locks cannot cause the build to lose its skeleton. The artist's file stays unchanged.

New MetaHuman drafts automatically receive the full Top/Pants/Shoes adapter.
Kit prerequisites finish before creating the source, and the exact inactive
draft/source link is saved before Blender preparation so it can be resumed.
Existing characters and artwork are not migrated. The portable program includes
the kit builder and generates private references from the user's installed game.

Settings → Use less memory in MetaHuman Creator is enabled by default. Studio
releases unused work buffers, avoids restoring unrelated editor tabs and uses
lighter preview settings. Display thumbnails retain smaller copies; painting
still uses the original artwork. Source textures and game-build quality remain
preserved. This does not bypass Unreal's memory checks or guarantee that a
particular PC can open a rigged character.

If Creator still fails, press Send to Rowe after the failure. Reports now include
the latest Studio-launched Creator outcome, memory snapshot and a bounded,
redacted Unreal log tail. A new Creator error can be sent even when Studio's
task text has not changed. Green confirms delivery. No background uploads.

Validation covers real Blender reference preservation/reopening, green display
overrides, complete adapter and draft-flow fixtures, actual clothing-screen
navigation/rendering, and the existing memory/workflow/bridge/report checks.
The new draft source in the kit-flow fixture is an identity stub; this is not a
new native MetaHuman build or gameplay acceptance. A real unrigged MetaHuman
copy opened and accepted a reversible face edit in the native editor. Independent
friend-PC recovery and full gameplay remain unverified. No universal fit is
claimed. Unreal portrait integration remains a separate prototype.
