# Hood Warfare 2 clothing for RoweMod Studio

Curated, editable clothing downloads for **Hood Warfare 2**. [Browse on RoweMods](https://rowemods.com/hood-warfare-2) or [browse GitHub Releases](https://github.com/xrowex/RoweMod-HoodWarfare2-Clothing/releases).

## First download: ROWE Pants

Custom UVs and artwork by **One**. Fits the **classic DeShawn body and game rig**. Includes the garment FBX, Base color and DirectX Normal PNGs. The authored orange ROWE design keeps its colors on both teams.

[Download ROWE Pants v0.1.0](https://github.com/xrowex/RoweMod-HoodWarfare2-Clothing/releases/download/rowe-pants-v0.1.0/ROWE-Pants-0.1.0.roweclothes)

1. Open RoweMod Studio, then **My clothes**.
2. Choose a **DeShawn-based character with the classic body**, then **Pants**.
3. Choose **Share -> Import Pants package** and select the downloaded `.roweclothes` file.
4. Choose **Build and Play**, then select your custom character in game.

Importing creates editable copies; it does not install the mod until Build and Play. A different body or rig requires refitting the garment first. Aqua's custom body is a different fitting target. Check walking, crouching, jumping, aiming and reloading after installing.

To customize the design, use **Textures -> Export for Substance / Import texture set**. To change its shape, use **Make clothing -> Get fitting kit**, fit and weight the mesh in Blender, then **Import finished Pants mesh**. Keep the matching UVs, weights, material slots and game rig.

## Publishing more clothing

This is a curated collection. Export an item through Studio's **Share -> Export package**, then provide the `.roweclothes` file, author name, matching body, screenshots, version and asset-sharing permission to the collection owner. Accepted items are published as GitHub Release assets and listed in `catalog.json`. The website reads this catalog; no public upload service is required.

## Compatibility and verification

Requires RoweMod Studio's clothing-package version 2 workflow and the supported Hood Warfare 2 game build. The package checks the base clothing, body fit, rest rig and payload hashes. It excludes full body, face, hair, scripts and cooked game containers.

Package import was verified in an isolated recipient. The matching source pants were checked in a local match; two-PC multiplayer is still untested. This first release is marked a prerelease for wider user testing.
