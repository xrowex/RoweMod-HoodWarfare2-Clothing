# RoweMod Studio 0.2.75 beta

Studio separates playing prepared mods from creating assets. First run offers **Set up for playing** or **Set up for creating**. Prepared player downloads need the supported game and cosmetic runtime, with no Epic, Unreal, Blender or mapping capture.

**Browse mods** shows subscriptions and creator downloads. **My mods** holds downloaded items. **Wardrobe** dresses an existing wearer; compatible prepared clothes also appear in the native Player Select Wardrobe. Switching clothes keeps the character identity. Authored characters can preserve garments and named outfits; classic ready-only profiles retain stock/prepared choices. Selections remain local and are not a multiplayer-sharing claim.

**Create** has three focused routes: **Edit textures** exports an existing item's FBX/maps for Substance and returns painted PNGs; **Make clothing** provides the real body/rig fitting kit and finished-mesh import; **Make a character** uses MetaHuman Creator/Skin Details and separate game preparation. Texture/item projects do not add a character. Fitting and weight painting remain manual authoring work.

ROWE Pants adds a curated ready-to-play `.roweplay` alongside its preserved `.roweclothes` source. Exact game/body/rig gates, archive/payload hashes, owned installs and interrupted-transaction recovery preserve unrelated assets. Different payloads sharing a native container identity are refused. Saved prepared copies retain their original cooked namespace even when owned external filenames change. Missing disabled Mask bindings can be captured without a source file; missing enabled maps still stop the action. UI-only outfit revisions do not change artwork identity.

The narrow clothing-cooker repair for Mutable import data passed an actual local native cook and separate 30 native/36 audit checks. Final candidate assembly package/ownership/rollback checks (70) and optional-map/signature checks (12) passed. Source-linked wardrobe regression passed separately. These checks do not substitute for gameplay.

Local native wardrobe acceptance is verified on the supported Steam build on the developer PC: stock-to-ROWE Player Select switching, saved selection after restart, and a DeShawn Crips match showing black ROWE pants, orange cuffs and correct feet after spawn, aiming, firing, reloading and brief movement/jump taps. Extended movement stress testing remains outstanding. Independent friend-PC setup-to-match, missing-vendor installs and two-PC multiplayer remain unverified. No automatic body fitting or cross-player wardrobe synchronization is claimed.

Studio 0.2.70 and newer receive verified updates automatically when enabled. Close Studio, the game and Unreal when ready to apply; projects, artwork and settings remain saved. Earlier installations need one manual download. Mod subscriptions check published updates; equip new assets with the game closed.
