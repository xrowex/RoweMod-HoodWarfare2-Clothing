# Studio 0.2.95 — One pants download, automatic body-fit selection

A multi-fit .roweplay bundle can contain separately verified pants variants for
stock characters, both teams and supported saved custom bodies. Subscribe once,
choose a wearer and Studio selects the exact matching body/rig profile. Matching
subscribed bundles also appear in that wearer's wardrobe. Players need no Blender
or Unreal to install the selected cooked fit.

My clothes -> pants item -> Build one pants download · all fits collects the
current stock/custom body profiles and revalidates their saved source-to-cook
fingerprints, native rig evidence and containers. Missing fits stop the export
with their names; use Add another body fit and finish/build each variant. This
is packaging and selection, not automatic geometric refitting. New custom body
shapes still need their own verified fit.

Submit pants with all fits attaches the bundle, creator source and preview to the
existing Google-authorized review workflow. The combined submission limit remains
31 MB; larger bundles stay saved locally. The website lists the included profiles
and serves one pinned download. Older Studio clients are not offered bundles they
cannot read; existing single-fit packages and saved outfits remain supported.

Validation: 25 native bundle/selection/installation fixture checks, nine native UI
checks, 68 existing single-fit transaction checks, 47 player wardrobe checks,
eleven publishing/recovery checks, fifteen website contract/auth/bundle tests and
seven local bundle upload/catalog/download checks. Synthetic fixture assets were
never installed in the real game. Actual artist fits still require appearance,
clipping and movement checks in game. No universal auto-fit or new friend-PC/game
acceptance is claimed. Package and updater verification is recorded separately.
