# RoweMod Studio 0.2.76 beta

Choose a task, choose a pictured starter and item, then follow one next action. Create offers Play mods, Edit textures, Make clothes and Make a character. The wearer/item heading stays visible. Nested editor tabs and the global part dropdown are replaced by guided pages.

Texture editing starts with the selected model and primary PNG export. Artwork shows Base color first; Normal and Mask are under Advanced. Built-in paint, import, reset and team-color controls remain available. New clothing has its own fitting-kit and mesh-import steps; arbitrary garments still require fitting and full game-rig weights in Blender.

Character appearance uses MetaHuman Creator with guided open, skin handoff/import, build and user-confirmed game checks. Skin import preserves the existing game rig; changed head/body geometry and hair still need their game preparation. Wardrobe uses wearer pictures, category buttons and garment cards, with one Play with outfit action. Missing photos use labeled illustrations.

Saved step records resume across launches. New artwork invalidates prior build/game-check completion. Failed or canceled operations do not mark a step complete. Successful cooked model-ID promotion retains legitimate progress. An unreadable checklist offers a metadata-only restart with a backup; models, artwork and project definitions are preserved. Ctrl+Enter cannot skip prerequisites.

Validation covers isolated workflow ordering/invalidation/preservation, actual offscreen WinForms callbacks/layouts including compact and large-font sizes, and retained PNG import/reset and package ownership checks against the final assembly. Game/runtime/cooked clothing payloads are unchanged from 0.2.75. Its prior local native wardrobe acceptance remains separate; this UI release does not establish a new friend-PC, Painter UI or multiplayer test.

Close Studio, Hood Warfare 2 and Unreal to apply an automatic update, then reopen your saved workspace. Previous releases remain available.
