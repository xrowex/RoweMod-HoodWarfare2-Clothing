# Studio 0.2.94 — Ready-to-play browsing

Browse mods now shows only clothing with a ready-to-play package and a matching
body profile. Player cards offer Subscribe or Update subscription, without an
editable-source download. An empty player catalog says that no ready mods are
published yet; source files are never presented as playable downloads.

Editable packages remain under Create -> Get editable clothing files. The
website's default catalog and gallery use the same separation, and player cards
show the playable package's download, size and checksum. Creator-only publishing
remains available in the explicitly labeled creator library.

Verified with seven isolated native UI checks, twelve website contract/auth
checks and thirty local upload, review, catalog, detail, download and revocation
checks. Synthetic routing fixtures are not playable assets or gameplay proof.
Existing user projects, artwork and subscriptions are preserved. The updater and
portable package are verified separately before release.

Each clothing body fit remains explicit. Sharing a MetaHuman rig does not make
pants fit every body; automatic universal fitting and multi-body player bundles
are not added by this update. No new gameplay or friend-PC acceptance is claimed.
