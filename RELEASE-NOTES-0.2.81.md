# RoweMod Studio 0.2.81 beta

Skin Details is paused. MetaHuman setup now requires only the matching Unreal installation and Creator Core Data; the extension and C++ preparation steps are removed. A failed optional extension build no longer blocks character editing.

Studio opens the exact linked character in plain MetaHuman Creator without installing or compiling RoweModSkinDetails. Previously enabled project entries are disabled on the next launch after Unreal is saved and closed, with the original project descriptor backed up. Existing plugin files, saved tattoo maps, models, characters and artwork are preserved. An already-open editor is left running until you save and close it.

Skin Details import/build controls and the old mandatory skin-handoff checklist are removed from the character workflow. Save in Creator, adapt changed Body/Face meshes and hair to the game rig, then Build & Play. Texture painting and Substance exports remain available. Geometry conversion and hair rigging are still explicit authoring work.

Actual assembly setup/launch/preservation checks and existing library/workflow checks passed. No newly installed vendor component, new editor-session or gameplay acceptance is claimed. The 0.2.80 saved-wardrobe library fix, automatic updates and removal of manual Steam build approval remain in place. Native runtime and helpers are unchanged.

Save work and close Studio to update, or extract the full current ZIP. No C++ workload is needed for plain Creator. If an older copy still shows the failed build, check that you opened the new version.
