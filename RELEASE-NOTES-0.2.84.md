# RoweMod Studio 0.2.84 beta

Save a MetaHuman in Creator, return to Studio and choose **Build & launch game**. Studio now prepares Body and Face on the native game rig, transfers compatible Creator hair/brows/lashes, fits the starter outfit and cooks the selectable character automatically. Existing saved MetaHuman drafts use the same route. Blender runs in the background; no manual FBX export, mesh adaptation or part import is required.

The 0.2.83 fix that keeps MetaHuman Creator open is retained. Skin Details remains paused. Matching Unreal 5.8.3, Blender and MetaHuman Creator data are still installed prerequisites. Original Creator assets, artwork, existing character definitions and saved wardrobe proofs are preserved.

Native hair includes a card fallback for the character-selection preview. Rebuilt clothing gets a fresh wardrobe selection revision so the game uses the newly prepared fit.

A fresh MetaHuman was exported, adapted, bound, cooked, independently reopened and visibly checked in the game's animated character-selection preview with its hairstyle and fitted outfit. Application regression checks and an isolated upgrade using the actual 0.2.83 updater passed. Full-match deformation, One's PC and two-PC multiplayer remain unverified; check movement, hair and outfit in a match before confirming the character.

Use **Settings → Check for updates**, wait for the download, then close Studio, Unreal and the game so the update can apply. Automatic updating is enabled by default. Older 0.2.77–0.2.81 installations whose updater rejects their existing inventory need one complete-ZIP manual update; preserve the old workspace and artwork.
