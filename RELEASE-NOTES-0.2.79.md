# RoweMod Studio 0.2.79 beta

Normal Steam updates no longer require a manually published game-build approval. Creator setup, Build & launch game and prepared clothing accept complete HW2 Steam installation metadata without a fixed build list or approval-feed request. The old pending-approval message is removed.

Steam installations mid-update or missing metadata still wait for completion. Detected anti-cheat protection still blocks cosmetic-loader setup. Clothing archive hashes, native container format, body/rig matching, file ownership and rollback protections remain in place. A Steam build ID alone no longer invalidates installed clothing receipts. A genuine rig or asset-format change can still require recooking or a Studio repair.

The 0.2.78 Player Select freeze repair is retained unchanged. The new current build 25921858 passed a read-only audit of all 30 publisher files; its existing Aqua selection and wardrobe were observed running. Exact new assembly checks cover newer/future numeric build identities, no-feed package installation and receipt retention, plus rejection of malformed identities, wrong-game packages, changed rigs and protected installations. No new custom garment, independent friend-PC or multiplayer acceptance is claimed.

Save your work and close Studio to apply the update; keep your existing fitting files. The character and clothing libraries and saved Blender workflow remain intact.
