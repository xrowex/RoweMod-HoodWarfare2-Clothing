# RoweMod Studio 0.2.80 beta

Saved character wardrobe items now appear in My clothes and Continue a project. Previously, Save current item stored a garment in the character wardrobe while My clothes only showed authoring projects and downloads. Existing saved pants and tops are discovered automatically; no resave, export or character recreation is needed.

Repeated saves with the same name, wearer and slot share one card. Open the card to choose its latest or earlier saved versions. Wear on the original character, or Equip & edit to work on an editable copy. The immutable saved garment, original artwork, character identity and exact body/rig checks stay intact. The clothing list shows a loading message while validating saved files.

The developer-PC Studio check shows Aqua Pants and Aqua Top in My clothes with the correct wearer and category. Source wardrobe/preservation and assembly workflow checks passed. Native runtime, authoring helpers and prepared game payloads are unchanged from 0.2.79. No new garment gameplay, independent friend-PC or multiplayer acceptance is claimed.

Automatic updates and the removal of manual Steam build approval are retained. Save work and close Studio to apply the update.
